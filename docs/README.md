## Web版での扱い

- Web版は、静的Webアプリとして公開している現行版です。
- デスクトップ版と共通する機能は、デスクトップ版仕様書を基準にします。
- ブラウザ固有の差分が必要になった場合のみ、このWeb版リポジトリ側に補足仕様を追加します。
